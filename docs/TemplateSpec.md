# NORAH Studio Template Spec v1.0

## 目的
Templateは、Theme、Lyrics、Motion、Layer、Export設定をまとめた再利用可能なプリセットである。

## Themeとの違い
```text
Theme = 世界観
Template = 制作設定一式
```

## Template候補
```text
Template
├ theme
├ background
├ particles
├ spectrum
├ ring
├ lyricsStyle
├ lyricsMotion
├ overlay
├ export
└ safeArea
```

## 将来例
```text
Minimal Lyric Video
Aurora Emotional
Cyber Vertical MV
Dark Club Visualizer
Neon Short Video
```
